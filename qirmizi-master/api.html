Открытые данные проекта

Статические API-эндпоинты не требуют ключа и генерируются при каждой сборке из актуального снимка OpenStreetMap. Исторические архивные материалы публикуются отдельно с учётом прав на конкретный файл.

QGIS

В QGIS можно открыть GeoJSON напрямую как векторный слой. Для рабочих копий с пользовательскими паспортами используйте KML/GeoJSON-экспорт из исследовательского интерфейса.

Модель идентификаторов

QQ-OSM-{osmId}   — постоянный ID здания
MAT-{uuid}        — архивный материал
AUD-{uuid}        — запись журнала изменений
