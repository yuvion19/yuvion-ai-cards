# UVMALL Telegram AI Admin — Render webhook deployment

**Сервис:** бот [@uv_mallbot](https://t.me/uv_mallbot), связь с клиентами — [@UVMALL19](https://t.me/UVMALL19).

Приложение обрабатывает Telegram Bot API webhook, без Telegram-паролей. В нём есть ответы на частые вопросы покупателей и продавцов, передача обращений менеджеру, согласие на заявку, опциональный ИИ через официальный GigaChat API и отключение автоматических ответов по слову «стоп».

## Настройки в Render

В Render откройте UVMALL Telegram AI Admin → Environment и добавьте секреты:

- `TELEGRAM_BOT_TOKEN`: токен именно бота @uv_mallbot, полученный через @BotFather. Никогда не передавайте токен в чат или GitHub.
- `ADMIN_CHAT_ID`: Telegram ID ответственного менеджера. Для UVMALL установлен `8771756849`. Чтобы бот мог писать в личные сообщения, менеджер должен хотя бы один раз открыть @uv_mallbot и нажать Start. При ошибке доставки бот честно предложит клиенту перейти на @UVMALL19.
- `OWNER_USER_ID`: необязательный ID владельца @UVMALL19. Если не задан, программа сверяет точное имя пользователя `@UVMALL19` в подтверждённом Telegram BusinessConnection.
- `OWNER_USERNAME`: по умолчанию `UVMALL19`, публичное имя аккаунта для проверки подключений. Не меняйте без проверки.
- `PRIVACY_POLICY_URL`: действительный URL политики обработки персональных данных, если будут приниматься заявки.
- `GIGACHAT_AUTH_KEY`: ключ авторизации GigaChat API (Base64 из личного кабинета). Хранить только в секретах Render. Никогда не публиковать в GitHub и не отправлять в чаты.
- `GIGACHAT_SCOPE`: `GIGACHAT_API_PERS` (по умолчанию), либо `GIGACHAT_API_B2B`/`GIGACHAT_API_CORP` в соответствии с тарифом. Приложение проверяет доступные scope и запоминает успешный.
- `GIGACHAT_MODEL`: `GigaChat-2` (по умолчанию, быстрые ответы на русском).
- `GIGACHAT_PROBE`: `1` — однократный тест OAuth и чата после запуска. Это расходует небольшое число токенов.

`WEBHOOK_SECRET` задаётся отдельно в Render; никогда не публикуйте его. `WEBHOOK_BASE_URL` можно не задавать, если Render выставляет `RENDER_EXTERNAL_URL` автоматически.

После добавления переменных запустите Redeploy. При запуске сервис автоматически вызывает `getMe` (сверяет username `uv_mallbot`) и `setWebhook`.

## Обычный Telegram @UVMALL19

В настройках Telegram найдите «Автоматизация чатов» и подключите @uv_mallbot. Ограничьте область действия входящими обращениями клиентов, исключив личные переписки; запросите минимальные права. Если раздела нет, проверьте обновление Telegram/доступность функции в аккаунте. Подключение собственно аккаунта требует действия владельца в Telegram — бот не может делать это за владельца.

## Render и ограничения бесплатного тарифа

Render Free Web Service может переходить в sleep при простое и запускаться при входящих webhook, что увеличивает задержку первой реакции. Для гарантированной непрерывной работы и устойчивого хранения заявок нужен платный или иным образом постоянно работающий сервис с базой данных. Текущий пилот не сохраняет состояние диалога на диске, а заявки пересылает менеджеру в Telegram; после перезапуска промежуточная форма сбрасывается.

## Проверка

- `GET /health` показывает `status: online` и флаги конфигурации (без секретов).
- В Telegram откройте @uv_mallbot, отправьте `/start`, `1`, `3`, `5`.
- Напишите боту `/myid` со своего Telegram, чтобы узнать собственный ID, а затем установите в Render как `ADMIN_CHAT_ID` и `OWNER_USER_ID`.
- Проверьте бизнес-автоматизацию с другого аккаунта, не содержащего личных переписок.

### Безопасность

Токен Telegram хранится исключительно в приватных переменных Render, не отправляйте логины, пароли или коды входа в ChatGPT. Запуск без `TELEGRAM_BOT_TOKEN` безопасен: HTTP-сервис отвечает, но не подключён к Telegram. Автоматические рассылки запрещены, AI-ответы не содержат неподтверждённые цены и сведения из закрытой базы.

## Безопасная замена токена

Если токен передавался в переписке, его следует перевыпустить в официальном @BotFather командой /revoke. Новый токен добавьте **только** в Render → Environment → TELEGRAM_BOT_TOKEN; затем дождитесь статуса Live и строки `Webhook registered for @uv_mallbot` в журнале. Старый токен перестанет работать. Не присылайте новый токен в чат.

## Telegram Chat Automation

В @BotFather включите для бота возможность подключаться к аккаунтам (Business Mode), если она выключена. В личном аккаунте @UVMALL19 откройте «Настройки → Автоматизация чатов», выберите @uv_mallbot и разрешите сообщения от новых клиентов, а не доступ ко всем личным чатам. Программа проверяет, что connected account соответствует @UVMALL19, и применяет разрешение `can_reply`. При необходимости можно использовать стабильный OWNER_USER_ID.


## Техническая интеграция: GigaChat API (ноябрь 2026)

Движок свободных ответов — официальный GigaChat, а не OpenAI. Используется получение access token через `https://ngw.devices.sberbank.ru:9443/api/v2/oauth`, затем `https://api.giga.chat/v1/chat/completions`. OAuth-токен кешируется примерно на 25 минут, чтобы не получать новый на каждый вопрос. TLS-соединение проверяется стандартными системными центрами сертификации и при необходимости публичным корневым сертификатом Минцифры с проверкой SHA-256 (проверка TLS для API не отключается).

Система не получает цены, наличие или реальные статусы из базы UVMALL и не должна их выдумывать. Стандартные FAQ-ответы о каталоге, кабинете и связи с менеджером работают без вызова ИИ. Перед передачей пользовательского текста GigaChat проверяются очевидные секреты и маскируются телефон/email. Для полноценной обработки персональных данных следует добавить публичную политику и настройки согласия. В открытые логи не выводятся авторизационные ключи и токены.

Проверка: `GET /health` возвращает `ai_provider`, `ai_enabled`, `gigachat_status`. Значение `chat_verified` означает, что GigaChat реально сгенерировал ответ в контрольном вызове. При `oauth_failed` проверьте действительность ключа и доступный тариф/квоту в кабинете Сбера. При `chat_http_error` проверьте модель и квоту. Если GigaChat недоступен, бот отвечает сценарными сообщениями.

Источники:
- https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/gigachat-api
- https://developers.sber.ru/docs/ru/gigachat/certificates
- https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/post-chat

Ключ авторизации, который был передан в личной переписке, стоит заменить в кабинете GigaChat API после первоначального теста и обновить значение в секретах Render. Новый ключ **не публиковать в переписке**.


## Раздел «Помощь» — версия 2

Помощь открывается через **/help** или через кнопку помощи на стартовом экране. В отдельном меню есть:
- **Арендаторам и продавцам** — подключение, кабинет, размещение товара, Excel, модерация и розничные/оптовые цены.
- **Покупателям** — поиск товаров, опт, контакт поставщика, заказы, доставка/самовывоз и возвраты.
- **Техническая помощь** — вход, загрузка фотографий, ошибки сайта и безопасность.
- **Спросить UVMALL AI** — клиент вводит вопрос своими словами; бот отвечает с учётом выбранной темы. Бот не имеет доступа к данным товара, заказа или модерации.
- **Менеджер** — если в Render есть `ADMIN_CHAT_ID`, бот уведомляет менеджера и приостанавливает автоответы; без этого ID показывает прямую ссылку @UVMALL19 и не обещает доставку обращения.

В личном чате **@uv_mallbot** меню содержит кнопки. В Telegram Chat Automation аккаунта **@UVMALL19** доступны текстовые команды (без callback-кнопок). После выбора «арендатор», «покупатель» или «техпомощь» можно ответить номером конкретного вопроса из списка: `помощь`, `арендатор`, `покупатель`, `техпомощь`, `спросить ИИ`, `менеджер`.

Команды бота: `/start`, `/help`, `/seller`, `/buyer`, `/tech`, `/ask`, `/manager`, `/myid`, `/stop`. Нажатие «Спросить UVMALL AI» переводит диалог в режим свободных вопросов до команды `меню` или `/help`.

Справочные материалы осторожны: регистрация, кабинеты и URL основаны на известных ссылках; они не подтверждают комиссию, гарантию наличия, статус заказа или действия интерфейса, которые не были проверены. Для спорных случаев предлагается менеджер.

**Проверки:** шесть локальных тестов `test_helpdesk.py` автоматически выполняются при запуске веб-сервиса без обращения к API; в логах ожидается запись `UVMALL Help Center ready: 6 tests passed, 16 topics`. Запуск можно подтвердить по `GET /health`, полям `help_enabled=true` и `help_topics=16`; реальный пользовательский сценарий проверяется отправкой `/help` в Telegram.

## Публичное название помощника

Клиентам показывается только бренд **UVMALL AI**: название и описание Telegram-бота, раздел помощи, кнопки, тексты подсказок, команды `/ask`. Название внутреннего провайдера остаётся в технических настройках сервера и этой инструкции для прозрачности и технической поддержки. Текущий провайдер — официальный GigaChat API.

Менеджер указан через `ADMIN_CHAT_ID=8771756849`. Бот подтверждает клиенту успешную передачу **только после ответа Telegram API**. Если менеджер не запустил @uv_mallbot, бот предложит клиенту написать напрямую @UVMALL19. Сообщения от менеджера или клиента с паролями, SMS-кодами и платёжными реквизитами не следует передавать боту.
