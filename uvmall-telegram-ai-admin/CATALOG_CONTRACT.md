# UVMALL AI — подключение каталога сайта

Статус на 17.11.2026: код Telegram-бота, Mini App и поискового API развёрнут. Публичная проверка uvmall.ru возвращала HTTP 503. Настоящих записей каталога пока нет. Бот не выдумывает товары, цены и остатки.

## Источник товаров

В серверных переменных Render можно настроить:

- CATALOG_FEED_URL — HTTPS-адрес экспорта JSON либо CSV, содержащего только опубликованные, одобренные товары UVMALL.
- CATALOG_FEED_TOKEN — необязательный Bearer-токен для чтения экспорта, если сайт защищает его.
- CATALOG_REFRESH_SEC — интервал синхронизации, по умолчанию 900 секунд.
- CATALOG_ADMIN_TOKEN — отдельный секрет для защищённого ручного обновления.
- GIGACHAT_MEDIA_MODEL — модель GigaChat-2-Pro для распознавания фотографий/аудио, при наличии доступа к ней.

Пример структуры файла (демонстрационные данные, НЕ реальные товары): объект с полем "products" (массив объектов), где каждый элемент содержит:
id: "sku-1"
title: "Название товара"
url: "https://uvmall.ru/products/sku-1"
image_url: "https://cdn.example.org/sku-1.jpg"
category: "Категория"
brand: "Бренд"
seller: "Название продавца"
pavilion: "Номер павильона"
description: "Описание"
price: 1500
wholesale_price: 1300
min_qty: 10
quantity: 100

Обязательны title и действительный публичный HTTPS URL товара на uvmall.ru; ID крайне желателен. Все остальные данные необязательны. Если цены и количество отсутствуют, бот пишет, что сведения нужно уточнить. Фото с внешнего CDN допускается только по HTTPS. Поддерживаются JSON и CSV с заголовками (включая русские колонки: название, категория, ссылка, цена, фото, опт).

Публиковать следует только прошедшие модерацию товары. Нельзя экспортировать закрытые документы продавцов, личные данные клиентов, внутренние заметки, пароли и токены. Рекомендуется обновлять записи после редактирования, модерации, изменения цены или остатка.

## Запущенные API и интерфейсы

- GET /health — технический статус, доступность ИИ, наличие каталога.
- GET /app — Telegram Mini App (предпросмотр также доступен в браузере).
- GET /api/catalog/status — статус синхронизации.
- GET /api/catalog/search?q=чайник&max_price=2000&qty=10 — поиск с фильтрами и оптом.
- GET /api/catalog/categories — реальные категории товаров.
- POST /api/rfq — передача оптовой заявки менеджеру после HMAC-проверки Telegram WebApp initData и согласия пользователя.
- POST /api/admin/catalog/refresh — защищённая Bearer-токеном синхронизация.
- POST /api/admin/catalog/import — разовая защищённая загрузка JSON/CSV. ВНИМАНИЕ: импорт в память бесплатного Render исчезнет после перезапуска, в продакшене нужен постоянный экспорт.

## Что умеет Telegram-бот

- /search чайник — подбор из настоящего каталога, до 5 результатов с фото, ценой и ссылкой.
- /catalog — кнопка Telegram Mini App.
- /wholesale — сбор оптовой заявки с согласием и передачей менеджеру.
- /help — 16 готовых справочных тем и свободные вопросы UVMALL AI.
- Поиск по фото или голосу — только после согласия клиента на отправку файла провайдеру GigaChat API. Модель выделяет слова запроса, затем работает текстовый поиск. Модель Pro может потребовать отдельного доступа.
- Mini App — фильтрация, избранное на устройстве, сравнение до 4 товаров, оптовые запросы.
- Inline Mode — обработчик реализован. Для включения в Telegram требуется действие владельца: @BotFather, команда /setinline, затем @uv_mallbot.

## Функции, которым потребуется ещё интеграция

- Реальный каталог и точные остатки: источник из UVMALL API/экспорта.
- Статусы заказов/модерации конкретных продавцов: авторизованный API кабинета seller.uvmall.ru.
- Массовая рассылка запросов нескольким поставщикам: подтверждённые контакты продавцов и их согласие. Сейчас заявки отправляются менеджеру.
- Уведомления о цене/поступлениях: долговременная база подписок, источник обновлений и согласие.
- Карта павильонов: координаты павильонов и связка товаров с планом ТК.
- Круглосуточная мгновенная работа: тариф Render без сна сервиса.
- Настоящее визуальное сравнение изображений: индекс фото каталога; текущий поиск по фото преобразует изображение в текст.

Важно: присланные ранее в переписке ключи Telegram и GigaChat следует перевыпустить у провайдеров и обновить непосредственно в секретах Render. Новые ключи не присылайте сюда.
