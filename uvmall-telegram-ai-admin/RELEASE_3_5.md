# UVMALL AI — версия 3.5: фактическое состояние

Проверено: 17 ноября 2026 г. Основной бот @uv_mallbot размещён на Render:
https://uvmall-telegram-ai-admin.onrender.com/

## Реализовано

1. Справочник UVMALL — 16 тем, а также свободные вопросы на основе GigaChat API под брендом UVMALL AI.
2. Переключение ответов UVMALL AI через /lang (ru/en/tg/uz/zh/fa/hi), с сохранением языкового выбора в базе. Проверка реального качества переводов для каждого языка не выполнялась; FAQ пока в основном русскоязычные.
3. Оценка ответов «Помогло/Не помогло» — без хранения текста обратной связи; один учёт на сообщение и пользователя.
4. Ограничение расходов ИИ: 25 вызовов модели в час на Telegram ID, SQLite. Временное хранилище может очищаться при деплое.
5. Проверка секретов и банковских карт перед отправкой текста в GigaChat API, маскирование телефонов и email. Пользователям запрещено отправлять пароли и документы.
6. Telegram /help, /search, /wholesale, /manager, /status, /site, /template, /checkfile, /panel (менеджер), /lang.
7. Продавцы могут скачивать CSV шаблон с /template и присылать документ .csv/.xlsx в @uv_mallbot. Бот проверяет до 2500 строк, отсутствие обязательных полей и повтор артикула. Байты файла остаются в RAM, не пересылаются GigaChat, не публикуются в личный кабинет. Проверяющий код протестирован на синтетических файлах; реальные файлы продавцов ещё не тестировались.
8. Панель оператора /operator доступна из кнопки Telegram по /panel для менеджера с ID 8771756849. Верификация по Telegram initData HMAC. Обращения имеют номера, статусы, ответы.
9. Ежечасный мониторинг uvmall.ru и здоровья бота настроен через ChatGPT. Отчёт — только при существенном изменении.
10. Анонимная агрегированная статистика поиска и отзывов, очистка закрытых обращений старше 90 дней.
11. Каталог: поисковое API, загрузка JSON/CSV, карточки и оптовые параметры реализованы, но без CATALOG_FEED_URL товары не загружены. Бот не выдумывает товары.
12. «Открыть сайт UVMALL» — обычная URL-кнопка на https://uvmall.ru/, а не встроенная Mini App.

## Что не получилось выполнить автономно

- Публичный сайт uvmall.ru отвечал HTTP 503/timeout из использованных сетей. В подключённом Render находится только сервис бота. GitHub доступен только с репозиторием yuvion-ai-cards. Сам сервер маркетплейса и его DNS-панель не обнаружены в доступных соединениях. Для восстановления нужен доступ к конкретному хостингу или репозиторию основного сайта.
- Синхронизация живого каталога невозможна, пока не доступен API/экспорт опубликованных товаров. Схема описана в CATALOG_CONTRACT.md.
- Надёжное долгосрочное хранение заказов и тикетов не реализовано: Render Free не имеет устойчивого диска, а среди подключённых Render Postgres нет экземпляров. Связанный Key Value сервер предназначен для другого проекта и не используется. Использование чужих баз Supabase исключено, для новой требуется отдельное создание.
- Ответы продавцам о фактических статусах модерации и заказов требуют авторизованного API seller.uvmall.ru и схемы разрешений.
- Автоматическое распределение оптовых заявок по нескольким поставщикам требует каталога продавцов и подтверждённых адресов.
- Уведомления об изменении цен требуют подписок и постоянной базы.
- Привязка павильонов к карте ТК требует набора координат/схемы.
- Ранее опубликованные в переписке токены Telegram и GigaChat следует перевыпустить через BotFather и кабинет GigaChat и заменить в секретах Render. В новом коде секреты не публикуются.

## Поддержка и безопасность

- Продакшен-команды не требуют загрузки секретов в GitHub.
- Любые действия продавца, изменяющие каталог или модерацию, нужно выполнять только с его подтверждения после соединения с настоящим API.
- Платные ресурсы и неизвестные аккаунты от имени пользователя не создавались.
- Ключи и пароли в чат повторно не запрашиваются.

## Исправления после проверки безопасности

- Заявки менеджеру теперь получают случайные 12-значные ID, чтобы после сброса временной SQLite не повторять старые номера и не отправить ответ чужому клиенту.
- Заявки на подключение продавцов включены в единую панель оператора, а не просто пересылаются сообщением без номера.
- В полях заявки блокируются ключи, пароли и банковские карты.
- Новые кнопки «Проверить сайт», «Шаблон Excel», «Выбрать язык» вынесены в справочное меню.
- Чтение CSV ограничено первым 2500 строками до создания списка, что снижает риск переполнения памяти.
